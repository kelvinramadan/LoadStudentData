# MVVM Background Process App

## Deskripsi
Aplikasi Android sederhana yang mendemonstrasikan penggunaan pola arsitektur MVVM dengan background processing dan local notification.

## Fitur
- Arsitektur MVVM (Model-View-ViewModel)
- Asynchronous data loading dengan Kotlin Coroutines
- Data JSON dari folder assets
- Local notification setelah proses selesai

## Tech Stack
- Kotlin
- Jetpack Compose
- MVVM Architecture
- Coroutines
- Gson
- Notification Manager

## Cara Menjalankan
1. Clone repository
2. Buka project dengan Android Studio
3. Run aplikasi pada emulator/device
4. Tekan tombol "Load Student Data"
5. Tunggu notifikasi muncul
